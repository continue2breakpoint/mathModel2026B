## 1. 逐条回应评审 §2

### 2.1 半径上下界的方向 —— **确认，已修正**

评审给的公式与反例都正确。`coverage.py` 现在的实现：

```python
def estimate_radius_bounds(region, readings, not_find_points, *, max_range_m, min_range_m):
    L = max(1000, max_{正例 p} min_{x∈P} |p-x|)      # 安全下界
    U = min(1500, min_{负例 q} max_{x∈P} |q-x|)      # 安全上界
```

* 删除了旧的 `R_hat = clip(min_q d(q,P), 1000, 1500)`（那既不是上界也不是下界）。
* `Belief` 上拆成 `radius_lo_m` / `radius_hi_m`；`radius_hat_m` 只作为下界别名保留。
* **规划半径 = `max(300, L - 50)`**，并且在 `directional=True` 时也用同一个下界
  （旧的"定向乐观口径可以放宽到 1540m"已删除 —— 定向与 R 的先验区间无关）。
* 负例圆盘排除半径改为 `L - margin`（原来是 `max(R_hat,1000)+40`，方向错了两次），
  并且**和覆盖判据用同一个半径**（见 §3.2）。
* 回归测试：`test_radius_bounds_direction_counterexample`（含评审的
  R=1000/真值 1020m/负例在原点那个反例）、
  `test_negative_evidence_never_raises_plan_radius_above_lower_bound`。

### 2.2 定向源必须维护同一朝向的联合可行性 —— **确认，已重写**

旧的 `invisible_mask` 逐正例做点积（"负例方向与**每个**正例方向点积非负 ⇒ 必定
可见"）确实不成立。新实现 `plausible_directional_mask`：

对候选源位置 x，记 `P_x` = 距 x 不超过 1500m 的正例、`Q_x` = 距 x 不超过 1500m 的负例：

1. `P_x` 空 ⇒ 证伪（源在 x 时看不到任何正例）；
2. `r_lo = max_{p∈P_x}|x-p|`、`r_hi = min_{q∈Q_x}|x-q|`，需要
   `r_lo <= r_hi` 且 `r_hi >= 1000`（**同一个 R 必须解释全部观测**）；
3. 只有 `|x-q| <= r_lo` 的负例才"任何允许的 R 都够得着"，必须由朝向解释；
4. 朝向存在性用**圆弧区间求交 + 挖洞**精确判定（`_has_feasible_heading`），
   不再采样：每个正例给出一个圆心角 `180°+2δ` 的可行弧，每个必须被挡住的负例
   给出一个 `±90°` 的禁区，`可行弧 − 并集(禁区) ≠ ∅` 即保留。

评审的两个反例都进了测试：

* `test_directional_joint_heading_counterexample_from_review`：
  0°/−20°、各 500m 时，朝向 80° 能同时解释两个观测（`u·Δ<0`），
  旧点积规则会错删；模型里 1° 示向度容差让 `u=90°`（切点）也算可行，
  所以这条要用**同一朝向求交**而不是逐点判断。
* `test_directional_three_surrounding_probes_falsify_center`：
  0°/120°/240° 三个 500m 测点 ⇒ 无朝向能同时避开三者，
  "任意有限测点都能被背对"确实错了。
* 另外补了 `test_directional_radius_must_be_joint`：负例比正例近时
  "不存在共同的 R" 也必须证伪 —— 这是旧逻辑完全没有的一条约束。

### 2.3 栅格与重复测量的保证范围 —— **确认，已修正**

* `CoverageGrid.mask_inside_polygon` 改成**栅格外包**：候选格先按包围盒取，
  格心在区域外的再做"闭正方形 × 凸多边形"分离轴相交测试，相交就纳入。
  细长/贴边区域不会再被整片漏掉。
  （`mask_inside_arena` 刻意保留**格心**口径并写了理由：Ω 是题目给的硬边界，
  源不可能在圆外；而判据的严格性由"格的四角都被覆盖"承担。把 Ω 的外包也
  算进来反而会引入 Ω 之外、布局不保证覆盖的点，让证书凭空失败。）
* "同格去重"只当**启发式**：`KnowledgeMatrix` 的格内重复检测不新增信息这一点
  在代码注释里已明确标为"节省检测的启发式"，没有当作"零信息增益定理"。
  严格证书只依赖几何覆盖，不依赖这条。
* 新增 `test_directional_mask_applies_radius_consistency` 等栅格级回归。

### 2.4 现有实验能支持什么 —— **确认，脚本已修**

`_bench_ab.py` 的 `--directional` 现在**同时**写进策略参数
（`MatrixParams(directional=True)`）并且按 `Q4Strategy` 构造矩阵策略。
`_bench_paper_q4.py` 增加 `--scan-layout` 以支持发现层消融。
旧 Q4 表格的解释已在本文与脚本 docstring 里作废说明。

`mock.world.average_clear_time_s` 的口径（退出前累计虚拟时间 / 清除数）
在 §4 的报告口径里如实标注为"含收尾扫描的每源平均"，不再当"逐目标完成时刻均值"。
`2-opt` 只作为**对照**：Q4 的发现层现在直接给出
`(N-1)·s` 的**下界**（见 §4），不再拿"某次实验省了 4.5%"当收益上界。

## 2. 评审 §3 第一优先：集合约束推断 + Q4 朝向覆盖

### 2.1 联合可行性推断

`coverage.plausible_directional_mask` 就是这条的落地：同一朝向 + 同一半径的
联合可行性，格级可计算。用于**剪枝**（把确定不可能的位置从候选区域删掉）。

### 2.2 朝向覆盖的充分条件 —— 已实现成可复算的证书

```python
heading_cover_condition(x, probes, radius_m=1000.0) -> bool
    # 记 S_x = {q : |q-x| <= 1000}，返回 min_convex_distance(x, S_x) <= 0
```

证明（分离定理，已写在 docstring）：若存在朝向 u 使所有 `q∈S_x` 都
`u·(q-x)<0`，则整片 `conv(S_x)` 被严格分离半平面覆盖；但
`Σλᵢ(qᵢ-x) = 0` 又要求加权平均不小于 0，矛盾。

配套：

* `min_convex_distance(point, points)`：用支撑函数对偶 + 三级方向搜索
  （最佳方向 → 90° 粗扫 → 三分细化）。数值上**只会低估**距离 ⇒ 偏保守。
* `heading_cover_layout(s=950)`：轴向三角网格，31 点。**可证**朝向完备：
  任意 x 落在边长 s 的格三角形里，三顶点都在 s ≤ 1000 内，
  `x ∈ conv{三顶点} ⊆ conv(S_x)`。
* `heading_cover_report(stops, step_m)`：数值抽样给出
  `worst_hull_m`（到凸包最坏距离）与 `worst_nearest_m`（到最近停点最坏距离）。
* 路径：`_unit_edge_hamiltonian_chain` 用 Warnsdorff DFS 找"全用单位边"的
  哈密顿链 ⇒ 开放路径长度**恰为下界 `(N-1)·s` = 28500m（s=950）**，
  比按网格序走（47754m）短 40%。这是**数学下界**，不是局部搜索的改善比例。

## 3. 修正口径后暴露的三个真实 bug（评审没提到，但更重要）

### 3.1 `--directional` 没进策略参数（口径 bug，评审已指出）

修正见 §1.2.4。修正后 Q4 基线从 12/30 掉到 **9/30** —— 旧表格完全不可用。

### 3.2 负例排除圆盘与覆盖判据用了**两个不同半径**（漏源相关）

旧代码：判据按 `plan_radius = L - 50 = 950` 算"这个停点能确认多少格"，
但负例排除按 `max(R_hat,1000)+40` 挖圆盘。两者之间留出一圈 10~90m 宽的环，
于是**任何"每个停点都 no_signal"的频道永远无法确认**，收尾只能靠
`_verification_sweep` 把整个布局重扫一遍。实测 30 seed 中每局白跑
**7262~8625m**（占全部路程约 40%）。

修正：排除半径 = `plan_radius_m`（与判据同一个量），且
`_verification_sweep` 改成"证书通过就直接返回"——因为
"证书通过"本身就意味着"每个停点都 no_signal 的频道已被证明不存在"，
再扫一遍是在证明同一件事。

### 3.3 定向源漏源的**真正根因**：圆盘覆盖 ≠ 发现保证（关键）

实测 Q4 seed 7 频道 2：

```
真值 (-1194,-1282)、朝向 209.9°、有效接收半径 1031m
最近停点 (-950,-1645)：距离 438m —— 完全在半径内
但"源 → 停点"方向 303.9°，与朝向相差 94.1° > 90° ⇒ 源看不到这个停点
```

源在**有效接收半径内**却不被发现。旧证书用的是 `mask_disk_corners`
（四角都在 950m 内即"已确认"），这在定向场景下是**错的方向**：
"某个停点在半径内"根本不保证"该位置的源会被发现"。

修正：`CoverageTracker.heading_cover`（`directional=True` 时自动打开）把
覆盖判据换成

```
covered = disk(plan_radius) ∩ heading_covered_cells
```

其中 `heading_covered_cells` = "格心到 `conv(S_x)` 的距离 ≤ 格对角线"的格
（Minkowski 腐蚀，保证整格都被朝向覆盖）。实现是**增量**的：每登记一个新停点
只并入它新增覆盖的格，O(1) 摊还，全布局 31 点算完 0.8s。

这一条把上面那个漏源堵住了。同时也说明：**Q4 不能用"圆盘覆盖"省停点**，
朝向完备布局（间距 ≤1000m 的三角网格）不是保守过头，而是**必需**的。

### 3.4 顺带修掉的定位失败模式：近乎共线的读数

实测 Q4 seed 2 频道 16：4 个读数落在 308.5°~309.8°（1.3° 分离），
可行域退化成一条细长条、最小包围圆 291m，清除 13 次全失败。
新增 `_geometry_is_poor` + `_transverse_probe`：射线夹角 < 20° 时，
**先做一次垂直于射线的横向补测**把交会角打开，再继续逼近。
修正后 seed 2 由 15/16 → 16/16（横向补测触发 12 次）。
