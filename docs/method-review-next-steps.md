# 阶段性数学方法评审与下一步建议

评审日期：2026-09-12；实现版本：`8f2f611`。本次将 `feat/knowledge-matrix` 快进合并到本地 `main`，保持算法实现原样。现有 69 项 pytest 测试通过；涉及本地 HTTP 的测试在允许创建 socket 的环境下完成。没有重新执行正式测试或整批 A/B 实验。

## 1. 对现有方法的评价

准确的算法定位是：**有界误差集合估计 + 几何覆盖设计 + 贪心序贯调度**。贪心本身属于启发式，不必为了升级而替换全部模块。

最值得保留的是：以频道为目标身份的证据台账；用真实测点与 ±1° 方位约束构造可行域；用最小包围圆半径不超过 20m 判断可保证清除的位置；在时间成本中同时考虑移动、切频、检测和清除。知识矩阵是进一步做约束推断或贝叶斯推断的合适接口，但矩阵这种数据结构本身不是新的优化算法。

当前实现有较强的工程可复现性，但“实测通过”与“对题目允许的全部场景有数学保证”需要区分。尤其是覆盖证书还存在以下问题。

## 2. 必须先校正的数学与实验口径

### 2.1 半径上下界的方向

对全向源，记位置为 x、接收半径为 R，可行位置集合为 P。

- 正例 p 给出 `||p-x|| <= R`，所以 `dist(p,P)` 是 R 的一个安全下界。
- 负例 q 给出 `R < ||q-x||`，所以 `max_{x∈P} ||q-x||` 是 R 的一个安全上界。
- 负例不能推出 `R < min_{x∈P} ||q-x||`，更不能据此增大“必定可接收”的半径。

可维护保守界：

```
L = max(1000, max_{正例 p} min_{x∈P} ||p-x||)
U = min(1500, min_{负例 q} max_{x∈P} ||q-x||)
```

无负例时 U=1500；严格不等号与数值容差另行处理。这些是安全的标量界，并不替代位置与半径的联合约束。

`coverage.py:estimate_radius` 用负例到 P 的最短距离估计 R；该量既不是一般成立的上界，也不是一般成立的下界。覆盖保证只能用 L；证明“该点必定收不到”应使用 U；负例圆盘排除也只能使用安全下界。`_not_find_exclusion` 对半径加 40m 的做法扩大排除区域，安全余量方向不对。

简单反例：R=1000，负例点到真实源 1020m，确实收不到；按 1040m 负例圆盘排除会把真实源排除。格子角点检验不能弥补半径逻辑的错误。

### 2.2 定向源必须维护同一个朝向的联合可行性

记朝向单位向量为 u。正例要求 `u·(p-x)>=0`；负例要求 `||q-x||>R` 或 `u·(q-x)<0`。所有观测必须共享同一个 u 和 R。

`invisible_mask` 中“负例方向与每个正例方向点积非负 ⇒ 必定可见”不成立。例如源在原点、朝向 80°，两个测点的方向分别为 0° 和 -20°，距离均为 500m。前者可见、后者不可见，但二者夹角仅 20°。现有点积判断会错误证伪。使用 R_max=1500 判定负例必然可见也不成立，因为实际 R 可能只有 1000。

文档中“任意有限测点都可以被一个定向源背对”也不成立：在候选源周围 0°、120°、240° 三个方向各放一个足够近的测点，就没有朝向能同时避开三者。

### 2.3 栅格与重复测量的保证范围

`mask_inside_polygon` 和 `mask_inside_arena` 只纳入格心位于区域内的格子，会漏掉与边界相交但格心在外的格子，也可能遗漏细长小区域。连续覆盖证书应先做区域的栅格外包，再证明所纳入的每个格子都被覆盖；只检查选中格子的四角还不充分。

题目只说“同一地点误差固定”，没有说同一个 120m 格子内的信息相同。同格去重可作为节省检测的启发式，不能作为零信息增益定理。

### 2.4 现有实验能支持什么

Q3 历史 30 seed：两策略都全清，平均定位清除时间的中位数 332.19→330.24 秒，约降 0.59%；检测次数中位数 142.5→132。支持“检测更少、时间接近”，不足以断言稳定显著提速。应比较同一 seed 的差值并报告区间。

`_bench_ab.py:run_one` 中 `directional` 只传给场景生成器；策略仍构造为 `MatrixParams(**params)`，默认 `directional=False`。因此文档命令 `--directional` 生成的 Q4 结果不能直接归因于开启定向逻辑的矩阵策略。当前脚本可用下面命令显式纠正参数后重新测量：

```
python3 _bench_ab.py --seeds 1-30 --directional --param directional=true
```

旧 Q4 的 11/30 全清也不足以支持题目的“确保全部清除”。漏源时更低的每源平均时间不能单独作为优越性依据。本次未重新生成这组数据。

`mock.world.average_clear_time_s` 实际使用“退出前累计虚拟时间 / 清除数”，包含清除后的验证扫描。对同一个全清案例，源数固定，最小化该指标等价于最小化总时间；不是逐目标完成时刻的平均，也不必然等于最后一个源清除时刻除以数量。因此不能以“只看尾巴”为理由否定路径优化。

历史文档中真值位置 2-opt 省约 4.5% 只是特定实验中的局部搜索改善，不是其他算法收益的数学上界；2-opt 不保证求得最优路线。

## 3. 推荐路线：先保证正确，再优化动作

### 第一优先：集合约束推断 + Q4 朝向覆盖

每频道维护 `(存在性, x, R, 类型, 朝向)` 的可行假设，保留无源假设；总数 10–16 是跨频道约束。已检测频道可先对 x 分格，在每个位置格维护可能的朝向区间并处理半径约束。角度区间求交比手写“同侧”规则更贴合题意。用于严格排除时需要区间外包，不能把有限粒子未命中当作不可能。

对于从未检出的频道，有一个直接的 Q4 几何设计原则。给定候选源位置 x，取实际测过该频道、且距离 x 不超过 1000m 的测点集合 S_x。若

```
x ∈ conv(S_x)
```

则任意发射朝向都有至少一个测点落在其可见半平面中。证明：若全部测点都不可见，则对同一个 u 有 `u·(s-x)<0`；但凸组合等于零会产生矛盾。实现时取凸包内部并留距离、角度余量更稳健。

这把 Q4 从“圆盘覆盖”提升为“距离范围内的朝向覆盖”。边界源还提示一个重要选择：题目允许机器狗离开目标圆域，适当设置外圈测点可以覆盖向外发射的定向源。先用安全但较密的外围/三角网布局建立兜底，再通过集合覆盖删除冗余停点、用路径局部搜索排序。严格证书需要对位置连续区域验证，不能只检查格心。

### 第二优先：短视野 rollout，复用现有贪心作为后续策略

建议先实现深度 2–3 的滚动决策，而不是直接上完整 POMDP 求解器。动作定义为“下一停点 + 该点检测的频道集合”，必要时加入清除动作。候选可直接复用现有逼近点、横向点、缺口点。

为每个候选动作，从当前可行假设中取一批一致的场景，模拟不同观测分支，再用现有贪心模拟后续成本。选择估计剩余总时间最低的动作，只执行第一步，然后用真实观测重新规划：

```
Q(b,a) ≈ cost(a) + mean_ω [后续贪心完成成本 | b,a,模拟观测ω]
```

移动成本用距离/5，检测 5 秒，切频按真实切换次数计，清除尝试按 5 秒计。未完成的 rollout 必须惩罚或接上保守兜底，不能截断后看起来更便宜。观测模型须保留同点误差固定的特点。场景不确定性可另用最坏值或高分位成本做稳健对照。

建议实验起点：每步 8–16 个动作、每动作 32–64 个共同场景、深度 2；这些只是计算预算起点，不是已验证最优参数。只优化当前最难频道或收尾阶段，控制墙钟时间。可插入 `_approach_target`、`_best_refine_stop`，再扩展到 `_gap_fill`。

这与现有失败的“到目标 + 到下一个最近目标”不同：rollout 比较的是执行检测后，根据可能的新观测继续行动的完整成本。

### 其他候选方法的适用位置

| 方法 | 建议用途 | 优先级与限制 |
| --- | --- | --- |
| 2-opt / relocate / Or-opt | 已发现目标或固定扫描停点的开放路径优化；固定当前起点，末点自由 | 成本低，值得做对照；每获得新观测后重算。将清除视为 20m 邻域访问还可增加灵活性 |
| 贝叶斯推断 / 粒子信念 | 对存在性、位置、半径、类型和朝向计算观测预测，服务 rollout | 适合第二阶段。题目只给误差范围，不给概率密度，均匀误差等必须注明为建模假设并做敏感性实验 |
| 贝叶斯网络 | 表达上述条件依赖 | 图模型不是动作规划算法；当前问题不必先搭通用大网络。各频道仅近似独立，总数约束带来耦合 |
| 信息增益 | 为补测动作生成候选或作为辅助评分 | 熵减不等于节省完成时间；必须计入旅行、检测和后续清除成本 |
| 遗传算法 | 离线联合优化外圈布局、停点删选或少量策略参数 | 适合保留到后续；适应度先考核全清和证书，再考核时间。在独立 seeds 上验证，避免拟合 mock |
| POMCP / MCTS | 更长视野的观测分支搜索 | 等短视野 rollout 有收益后再做；连续角度观测需分桶或渐进扩展，并验证近似偏差 |

上述推荐是结合本题结构的工程判断，不是已测出的提速承诺。参考：有限轮次自适应的信息路径规划研究说明“观测—规划—再观测”的建模方向可行，但其特定目标与假设不自动适用于本题：[Tan 等，2024](https://proceedings.mlr.press/v238/tan24a.html)。POMCP 将粒子信念更新与蒙特卡洛树搜索结合，为后续更大规模规划提供参考：[Silver 与 Veness，2010](https://proceedings.neurips.cc/paper/2010/hash/edfbe1afcf9246bb0d40eb4d8027d90f-Abstract.html)。

## 4. 下一轮实验设计

按顺序比较：原始矩阵基线 → 修正保守证书/定向约束 → 加 2-opt → 加两步 rollout → 有依据后再加概率推断或离线遗传优化。每次只改变一个层面。

调参与验证使用分离的 seeds；所有方案在同一验证场景上配对。增加 R=1000、圆域边界、朝外定向、窄可行域、同格不同观测、全定向等压力案例。策略只能访问协议响应，不得访问实验器中的隐藏源真值。

先报告全清场数、漏源数及失败原因，再报告配对的总时间/每源时间差、均值与高分位、检测次数和墙钟时间。漏源案例另列，避免幸存者偏差。数学保证依赖证明和保守实现；再多随机成功案例也不能替代证明。

当前 `script/run.py` 默认仍选 `q3`。要使用矩阵策略需显式指定 `--strategy matrix`，Q4 再加 `--directional`。本地 mock 和接口链路验证不能替代官方物理环境的演练。
