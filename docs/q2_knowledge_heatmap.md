# 题目 2：单频道知识矩阵 → 下一观测点热图

启动 `python3 script/q2_dashboard.py --port 8055`，打开
`http://127.0.0.1:8055/matrix`。这一页与双点交会页是**同一个统一编辑台**的两个工作区
（顶栏一键切换，编辑台可收起 / 半屏 / 全屏，辅助线与导入导出面板完全共用），
共用的外壳与图层说明见 [题目 2 统一编辑台](./q2_unified_ui.md)；本文只讲本工作区的模型口径。

本页用于一个尚未清除的**全向源**；坐标是世界坐标（米），角度从 +x 轴逆时针计算。
矩阵的每列保存真实观测点及状态：`find`（示向角 ±1°）、`not_find`、
`not_measure`、`near`（5 m 内无法测向）。支持只含负例或尚无实际观测。
同坐标的重复记录去重，矛盾记录拒绝；下一观测点恰为已有坐标时使用原结果，不重新抽取误差。
这里仅检测坐标完全相同的重测，不额外按网格合并相邻观测点。

## 模型与计算口径

源点 G 在半径 1800 m 场地内有均匀面积先验，源自身的有效距离
ρ 在 [a,b] 上均匀，且**所有测量共用同一个 ρ**。
不同地点的测向误差独立均匀于 [-1°,1°]。

令正例集合 H 包括 find、near，负例集合为 M。给定 G 后：

```
L(G) = max(a, max_{i∈H} |G-P_i|)
U(G) = min(b, min_{j∈M} |G-P_j|)
w(G) = max(0, U(G)-L(G))
```

另施加场地边界、所有 find 的角区间与距离 >5 m、所有 near 的距离 ≤5 m。
无正例/负例时，对应 max/min 不增加约束。后验密度正比于 w(G)。
负例给出 ρ < 距离；连续均匀模型中端点不影响积分，固定 ρ 模型中保留严格不等号。
固定半径模式以满足全部约束的指示函数取代 w。

候选观测点 S 对应 d=|G-S|，检测概率权重为：

```
w_hit(G,S) = max(0, U(G)-max(L(G),d))
p_det(S) = ∫ w_hit(G,S) dG / ∫ w(G) dG
```

因此收紧有效距离并不需要增加积分维度，ρ 已解析积分掉。
测到后 d≤5 是 near，否则有示向角 β(G,S)+δ。未测到也是一个有信息的结果。

为了控制非凸几何成本，**用于评价定位尺寸的集合采用保守端点模型**：

```
A = 场地 ∩ 所有 find 楔形 ∩ 所有正例的 b 圆盘
    ∩ 所有 near 的 5 m 圆盘
    \ 所有负例的 a 圆盘 \ 所有 find 的 5 m 圆盘
```

后续结果仍按这个规则更新：未测到排除 a 圆盘，near 交 5 m 与 b 圆盘，
find 交楔形及 b 圆盘并排除 5 m 圆盘。固定模式中 a=b=ρ。
**概率权重使用共同 ρ 的全部约束；几何未进一步删除 L(G)>U(G) 的位置**。
这正是“可能区域取最大 1500 m，不可能区域排除最小 1000 m”的保守版本，
并非共同 ρ 联合后验支撑集的精确投影。

对几何泛函 f(A)，页面提供：

- 全部结果：E[f(A_after)]，包括未测到、near、测向。适合比较候选点整体表现。
- 条件于测到：E[f(A_after) | detected]，与旧页面口径接近；包含 near。
- 方差：对同一条件下的结果分布计算中心二阶矩。
- 检测概率：选择“方差”时是检测指示变量的 p(1-p)。

条件于测到且 p_det=0 时显示空值；无条件统计仍有“未测到”后的区域尺寸。
区域外的盲点不会因为没有成功样本而显示成 0 半径。

## 非凸几何和数值积分

实现不依赖新增第三方库，复用 NumPy、Flask、Plotly 与现有 C++ 几何核。

1. 区域保存成内部互不重叠的凸多边形集合。负例圆盘的补集通过半平面逐片分割，
   保留孔洞和分裂分支，不能以所有顶点的凸包替代面积或下一次更新。
2. 正圆盘用外接多边形，排除圆盘用内接多边形，因此几何近似包含真实端点模型区域。
   圆盘外接误差为 R(sec(π/n)-1)，内接误差为 R(1-cos(π/n))。
3. 每个凸片按中心扇形三角剖分，在三角形内用 Duffy 变换与 Gauss–Legendre 张量求积。
   积分节点上再次检查精确圆约束，并计算 w、w_hit。
4. 对预测示向角分段，每段概率由各源积分节点的 [β-1°,β+1°] 与该段的重叠长度计算；
   用段内概率加权角度代表该段，构造结果区域。这是角度分段求积近似。
   跨越 0°/360° 时，在预测角的最大空隙处展开。
5. C++ Welzl 算法对所有片的顶点求最小包围圆；区域面积按片相加。

**数值求积不是精确连续积分，也不是保证分区的证明**。先验权重存在折点、
狭窄可行带与内部观测的宽角分布时，应提高 `order`、`angle_bins`、`sides`，
分别比较候选点数值是否稳定。更密的热图网格只增加候选点，不提高单点积分精度。
若积分为零，界面报告“观测可能矛盾或有效区域过窄”，不会自动退回单次观测。

默认参考例 S1=(0,0)、θ1=0°、S=(850,520)：加密到
order=8、angle_bins=192、sides=360，E[Rmin]≈25.351 m，Var≈73.700 m²，
与原双点文档的 25.36 m、8.575² m² 一致到数值近似精度。

## 20 m 圆覆盖数的限制

N20 仍是**多边形近似区域的最少覆盖数下界**，不是精确最少覆盖数：

- Rmin≤20：1；否则至少为 2；
- 面积下界 ceil(area/(π·20²))；
- 在 180 个方向计算区域投影的区间并集长度 ℓ，使用 ceil(max ℓ/40)。每个覆盖圆的投影长度为 40 m，故这个下界对任意分裂集合都成立。

对分裂集合，直径/40 不是合法下界：两个相距 1000 m 的小块可能只需要两个圆。
实现使用投影并集长度而不是投影两端间的距离，结果不依赖于凸片如何划分。保守多边形的下界不必是
真实曲边区域的下界，尤其在整数阈值附近，应加密圆周近似。
Rmin 则是保守几何区域的最小包围圆半径。

## 编辑与导入导出

观测表就在编辑台里编辑：频道号、每个观测点的真实坐标、状态（`find` / `not_find` /
`not_measure` / `near`）与示向角，可增删列；点热图可取候选点并"加入观测表"作为待测列。
编辑台的"数据"小节与双点工作区是同一份组件：导出 / 复制 JSON、导出 / 复制 Markdown、
拖放或选择文件导入、粘贴文本框导入、从剪贴板读取。

无损单频道 JSON（本页另存 ρ 模型、绘图范围与显示参数）：

```json
{
  "schema": "q2-channel/v1",
  "channel": 1,
  "columns": [
    {"point": [0, 0], "status": "find", "bearing_deg": 0},
    {"point": [850, 520], "status": "not_measure"}
  ]
}
```

也可导入项目已有的 Channel × Path Markdown 表，选择其中一个频道。
接受 `angle.svd`，或宽度为 2° 的 `angle.lower/upper`（含跨零区间）。
旧版 `KnowledgeMatrix.as_dict()` 缺少真实观测坐标，因此不直接接受其 JSON；
旧版 Markdown 的表头是格心，按表头坐标使用，精度受原导出格式限制。
本页 JSON 和 Markdown 导出均保留所输入的坐标。

**跨工作区互转**：本页观测表可一键"载入到双点工作区"（需要恰好一个 `find` 观测，
否则给出明确提示而不是静默取一个）；双点工作区也可以把 S1 作为一列 `find` 观测
"转到知识矩阵工作区"。两个方向的 Markdown 都是同一张 Channel × Path 表，可直接互相粘贴。

## 分区判定与辅助线几何

热图响应里每个格点除了数值还带一个分区：

| 分区 | 判定 | 含义 |
| --- | --- | --- |
| `certain` | `p_det ≥ 1 − 1e−9` | 所有正权重源点都满足 `d < U(G)`，下一次读数必然成功 |
| `probabilistic` | `0 < p_det < 1` | 介于两者之间 |
| `blind` | `p_det ≤ 1e−12` | 所有正权重源点都测不到，该格点没有信息、不渲染热值 |

注意这里的"必然测到"用的是 `U(G) = min(b, min_j |G−M_j|)`（无负例时为 `b = ρ_max`），
而双点工作区的三区是按 `ρ_min` 取最坏情况判定的；两个口径都写在界面图例与面板里，不混用。

`MatrixEngine.observation_regions()` 另外给出每条观测自己的约束几何（find 的可行域与
±1° 射线端点、near 的 5 m 盘、not_find 被排除的 ρ_min 圆盘），前端据此绘制全部辅助线图层。
