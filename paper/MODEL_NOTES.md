# 论文与实现的衔接说明

本次仅增加 `paper/`，不修改现有策略和实验代码。第四问解法按要求留白；代码快照中的混合场景代码只是保存原文件，不代表论文采纳该问解法。

## 已修正到论文中的知识点

1. `framework/docs/modeling.md` 中“凸域下直径与包围半径相等”不成立。准确关系为 `D/2 <= r_* <= D/sqrt(3)`。`D<=40` 不能保证20米清除，论文使用包围圆逐顶点认证。
2. `geometry.polygon_layout_cover_radius` 的内部项 `ring_radius*sin(pi/n)` 不正确。中心加正多边形的内部极值为 `ring_radius/(2*cos(pi/n))`，详见附录。默认六边形1200米和八边形1010米均由边界项主导，原错误暂未改变这两个布局的覆盖数值，但一般参数会错，例如六边形1800米时真实覆盖半径约1039.23米。下界函数中的对应上界也应改成 `2*cover_radius*cos(pi/n)`。
3. 第二检测点保证三圆交的证明不能声称圆弧扇形只有三个极点。论文用单位向量正组合和半径分段，给出充分性证明。完整未截扇形含原点时三圆交是准确保证区域；排除5米小圆或裁剪目标圆后它通常只是安全内近似。
4. 无信号严格排除判据为距离 `>1500`；等于1500时仍可能接收。连续先验下概率零不等于逻辑不可能。
5. 后验第一读数为 `direction` 时应排除半径5米小圆。参考模型均值855.263米，严格处理后约855.277米。第二次 `near` 应单列，不生成一个不存在的示向度。
6. 数值求积是近似积分，圆盘外接多边形是保守近似，均不称为几何或积分“精确”。没有将旧文档里参考概率表直接复制成最终论文结果。
7. 光学清除失败3秒，成功5秒；`clear` 不切换测向频道。总时间为 `L/5 + N_s + 5*N_m + 3*N_o + 2*N_c`。
8. 现有基础策略把0至180度方位差截到90度，会把反向共线错误评为优良。论文使用无方向直线锐夹角，仍需代码跟进。
9. `_region_samples` 取顶点、边内插点及中心，并非等面积均匀抽样。论文只称代表点的启发式均值。
10. 最近邻加2-opt是可行路径上界或局部改进，不是全局最优路径下界。论文没有沿用相关旧文档中的最优性说法。

## 后续建议优先实现

- 几何异常与退化区域：区分空集、单点、线段；空域不得自动标记不存在；最小包围圆最后遍历顶点核验。
- 修正通用覆盖公式及测试，证书只用向保守方向的近似；检查整格，不能只检查格心。
- 将 `code/fallback_grid.py` 接入第三问的补测耗尽分支。原型只生成点，不发送动作。最多225次尝试的保证已证明；真实通信预算仍需验证。
- 严格逐频道终止：成功清除，或该频道的无信号点覆盖整个目标圆，才可报告完成。
- 更合理的候选点夹角、接收筛选和深度2至3的短视野规划。不要只优化当前移动而忘记补测后的清除移动。
- 补齐问题二任意第一点的目标圆裁剪、第二接收圆、近距分支，再做求积收敛与不同先验敏感性。

### 数据结构相关的实现边界（论文已区分）

1. 同地点读数固定不代表同一120米格内读数固定，5米是近距反馈阈值，也不是同误差位置的合并尺度。几何使用真实坐标；去重宜用精确位置或可证明的信息等价条件。
2. 现有单元格写入会覆盖同格旧观测。保留全部历史时知识集合才单调收缩；建议格键下面挂真实位置子表或事件编号列表。`mark_channel_cleared` 可更新任务态，但原始事件不要覆盖掉。
3. `build_beliefs` 将 `clear_fail_points` 附加到 `not_find_points`，语义不成立：清除失败仅排除20米，不能约束为无线电距离超过1000米。论文联合约束已分列；后续代码应改。
4. `_channels_to_probe` 以距离超过 `plan_radius` 为一定无信号的解释不成立。保证不可能接收使用半径上界 `U`；计划下界仅用于保证覆盖。原筛选可作效率启发，但不能拿它排除目标存在。
5. `_best_refine_stop` 当前用候选到旧检测点的距离和方向作代理，不是严格接收/交会证明；论文给出基于名义目标的锐夹角表达并单独检查可接收性。
6. 最近点逼近不是包围圆心，不能保证最近点到真实源距离小于包围半径；分段沿线逼近也不能保证“两读数即可20米清除”。
7. `_probe_at` 末尾登记部分停点时，应使用实际已执行频道列表。预算中断后不能把预定但未测的频道登记为已确认。
8. 当前 Markdown / JSON 单元格导出主要保留状态和角度，不能声称包含全部真实坐标和无损历史。精确复盘应保留事件日志，并扩展机读导出；摘要表只是展示视图。
9. `KnowledgeMatrix.radius_bounds` 及导出的旧半径字段存在历史口径，论文半径界以 `coverage.estimate_radius_bounds` 的正例下界/负例上界为准。

这些说明用于后续让代码适应论文，不否定用户已观察到的 matrix 线上优势，也没有在本轮修改原策略实现。
