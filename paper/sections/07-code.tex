\texttt{strategy\_matrix.py}&第三问主策略：矩阵写入、选择性检测、成批精化、自适应逼近与缺口补测；第四问代码不作为本文该问解法。\\
\texttt{verify\_formulas.py}&本次新增的离线公式复核程序；检验覆盖极值、候选点裕量、后验均值和兜底单元尺度。\\
