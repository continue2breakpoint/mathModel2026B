\subsection{代码文件目录}
本附录仅陈列前三问相关的核心算法文件。论文目录下的 \texttt{code/} 保存了编写时的源码快照，路径与哈希见 \texttt{code/MANIFEST.md}；完整运行仍需仓库框架与依赖。表中的“已有”表示仓库已有实现，不表示已经实现本文全部改进。
\begin{longtable}{>{\raggedright\arraybackslash\scriptsize}p{5.1cm}p{8.9cm}}
\toprule
文件（省略公共前缀）&作用及与论文关系\\\midrule\endhead
\texttt{geometry.py}&半平面裁剪、圆盘外包络、顶点直径、最小包围圆；通用覆盖公式与退化处理需要按本文校正。\\
\texttt{cpp/geom.hpp}\newline\texttt{bindings.cpp}&C++几何内核及Python接口，用于直径、最小包围圆与求积加速。\\

\texttt{strategy.py}&问题三基础扫描、目标调度、局部补测和清除；需接入本文有限兜底和修正夹角评价。\\
\texttt{coverage.py}\newline\texttt{strategy\_matrix.py}&联合状态、覆盖及调度扩展；仅作为第三问改进的实现参考，其第四问代码不构成本文第四问解法。\\
\texttt{verify\_formulas.py}&本次新增的离线公式复核程序；检验覆盖极值、候选点裕量、后验均值和兜底单元尺度。\\
\bottomrule
\end{longtable}
