\subsection{评价指标与已有记录}
对每个案例，按题目口径计算
\begin{equation}
\eta=\frac{N_c}{N_{\rm true}},\qquad
\bar t=\frac{T}{N_c}\quad(N_c>0).
\end{equation}
无目标被清除时，$\bar t$ 未定义，应报告失败，不能填零。跨案例汇总应区分单案例 $\bar t$ 的均值、中位数与合并比值 $\sum T/\sum N_c$，三者一般不相同。总时间包含为确保未遗漏而进行的收尾动作。

\subsection{建议的验证与敏感性分析}
\begin{enumerate}
\item 几何正确性：检验角度跨零、近乎平行、反向共线、单点和线段退化，以及真值落在外接多边形内部的性质；用枚举直径核对旋转卡壳。
\item 覆盖可靠性：对解析最坏点、目标圆边界和扇区中线测试；栅格版本采用整格界，不把格心覆盖当成整格覆盖。
\item 策略消融：固定同一批案例，分别比较频道顺序与最近邻、不同补测准则、是否启用联合半径剪枝；同步报告失败案例。
\item 参数敏感性：改变扫描半径、近距候选半径、补测预算与数值包络精度，观察清除率和时间的变化；区分改变题设参数的稳健性试验与同题参数调优。
\item 官方验证：确认协议计时与状态更新正确后，在官方演练中记录失败类型，再填写正式测试结果；不得用本地模拟数量作为在线策略的可见信息。
\end{enumerate}

\section{模型评价}
模型的优点是将角度区间、接收距离和清除半径统一为集合约束；每次清除可以核验，未知目标数量通过逐频道覆盖证书处理。第二点的稳健接收区域不依赖人为先验，便于与概率排序分离。

模型的局限在于外包络会牺牲定位精度；正观测凸集没有充分利用负观测；最近邻和单步补测都是启发式，尚无全局最短时间保证。先验只描述参考场景，不能代替官方误差环境。有限网格兜底补足理论清除保证，但需要后续实现与实际时限验证。第四问尚待建立模型。
