\section{模型检验与结果记录}
\subsection{评价指标}
对每个案例，按题目口径计算
\begin{equation}
\eta=\frac{N_c}{N_{\rm true}},\qquad
\bar t=\frac{T}{N_c}\quad(N_c>0).
\end{equation}
无目标被清除时，$\bar t$ 未定义，应报告失败，不能填零。跨案例汇总应区分单案例 $\bar t$ 的均值、中位数与合并比值 $\sum T/\sum N_c$，三者一般不相同。总时间包含为确保未遗漏而进行的收尾动作。

\subsection{数据结构带来的收益如何解释}
矩阵的收益应落实到具体动作差异。对清除数相同的两次可比执行，记差值为“q3 减 matrix”，由时间公式得到
\begin{equation}
\Delta T=\Delta L/5+\Delta N_s+5\Delta N_m+3\Delta N_o,
\label{eq:matrixsaving}
\end{equation}
成功清除项相同而抵消。路径缩短应进一步分解为共享精化移动、逼近移动和收尾移动；检测减少应区分已完成频道、历史重复和低收益候选的跳过。不能把矩阵所有收益都归于扫描环的变化。

\subsection{建议的验证与敏感性分析}
\begin{enumerate}
\item 几何正确性：检验角度跨零、近乎平行、反向共线、单点和线段退化，以及真值落在外接多边形内部的性质；用枚举直径核对旋转卡壳。
\item 覆盖可靠性：对解析最坏点、目标圆边界和扇区中线测试；栅格版本采用整格界，不把格心覆盖当成整格覆盖。
\item 策略消融：在可比案例上固定其余模块，分别关闭负反馈剪枝、成批精化、缺口停止与自适应逼近；另以相同扫描布局比较 q3 和 matrix，区分数据结构支持的决策收益与布局收益。
\item 参数敏感性：改变扫描半径、近距候选半径、补测预算与数值包络精度，观察清除率和时间的变化；区分改变题设参数的稳健性试验与同题参数调优。
\item 官方验证：确认协议计时与状态更新正确后，在官方演练中记录失败类型，再填写正式测试结果；不得用本地模拟数量作为在线策略的可见信息。
\end{enumerate}

\section{模型评价}
本文的主要改进是所设计的频道—路径知识矩阵。它将每个目标的纵向证据与一个停点上的横向任务放在同一结构中，使负反馈、批量测量和覆盖证书可以共同参与决策。连续几何保持位置精度，离散矩阵与位掩码降低查询和候选评价成本，动作原因可从证据链中追溯。

matrix 的实用优势通过真实线上比较评价，理论部分给出证据更新、半径界与覆盖条件。其局限在于启发式调度尚无全局最短时间保证，压缩单元格需要防止覆盖旧证据，覆盖栅格需保持整格保守性；近共线情形仍需横向补测或兜底。本文将这些实现边界与模型保证分开。第四问解法继续留空。
