题目 2 · 根据知识矩阵选择下一观测点

输入一个尚未清除的全向源频道。坐标采用世界坐标（米），示向角从 +x 轴逆时针计量，误差 ±1°。所有观测共用同一个有效距离 ρ。

知识矩阵

粘贴导入 JSON / 知识矩阵 Markdown

Markdown 可包含多个频道，按上方频道号选择一行。JSON 保存真实坐标；旧版 matrix 导出的 Markdown 只有格心坐标，导入时按表头坐标计算。

计算设置


定位区域采用保守端点：正例半径取上限，负例仅排除下限；概率权重则使用全部观测对共同 ρ 的约束。N20 是多边形近似区域的覆盖数下界，未求解连续圆覆盖的精确最优值。进入 5 m 内按 near 结果处理；相同坐标重测不产生新信息。


设置矩阵后点击计算。高精度适合缩小绘图范围后比较。

采用确定性数值求积；提高求积阶数、角度段数与圆周边数比较结果，可检查数值收敛。图中概率不作为连续区域的“保证测到”证明。

点击热图查看候选点；可将该点添加为新的待测列。
