# 建模骨架

## 有界角误差

示向度误差为固定有界误差 ±1°。一次测向对应角宽 2° 的可行扇形，适合集合估计，
而非默认高斯最小二乘。关键补充：**同一地点重复检测读数不变**（附录2-1），
所以不能靠重复采样取平均消噪；只有换检测点才能获得新信息。

形式上：第 i 次读数给出约束
`|wrap(θ_i − atan2(y−y_i, x−x_i))| <= 1°`，
即一条过 `(x_i, y_i)`、方向为 `θ_i` 的**两条射线之间的楔形区域**。
这些楔形的交就是必定包含真值的保守可行域（凸，可用半平面裁剪精确计算）。

## 距离约束（容易被忽略但很关键）

`direction` 读数只在距离不超过该源有效接收半径时出现，而有效接收半径
`R ∈ [1000, 1500]`（附录2-2）。因此一次 `direction` 读数还给出
`dist((x,y), (x_i,y_i)) <= 1500`——这是一个**凸**约束（圆盘）。
只有两条射线时可行域往往是一条无界/细长条带（经典的角度交会测距模糊），
加上这个圆盘约束立刻变成有界区域。`geometry.clip_by_circle` 用**外接**正多边形
近似圆盘，保证结果仍是真值的上界，不会误判。

## 清除判据

清除成功只与"清除点与干扰源的距离 <= 20m"有关，与覆盖角无关（附录2-8）。
设可行域的最小包围圆为 `(c, ρ)`，真值必在域内，故 `|c − 真值| <= ρ`。
于是 `ρ <= 20m` 时瞄准 `c` 执行 `/clear` 形成**确定性判据**。

需要注意的是可行域的**直径**与包围半径同量级（凸域下相等）。
距离 `d` 处读数的横向不确定度约为 `d·tan(1°)`：

| 检测点距源 | 横向不确定度 |
| --- | --- |
| 1400 m | 24.4 m |
| 800 m | 14.0 m |
| 300 m | 5.2 m |
| 100 m | 1.7 m |
| 25 m | 0.4 m |

所以远距交会只能把可行域收到几十米（三个分离良好的 1000m 级读数约 60m 直径），
**达不到** 20m 判据；必须再逼近补读数。这就是策略里"远距扫描 → 逼近 → 清除"
三段式的原因。附录2-9 还给了捷径：距离 <= 5m 时信号过强无法测向（`near`），
此时可直接光学定位清除——逼近到位后经常直接命中这条路径。

## Q3 搜索

全向源接收半径至少 1000m。覆盖半径（区域内任一点到最近检测点的最大距离）
不超过 1000m 即可保证不漏源。圆心 + 半径 `r` 正六边形六顶点共 7 点的覆盖半径为

```
c(r) = max( r/√3 ,                              // 内部三角形外心（Voronoi 顶点）
            max_{t ∈ [r, 1800]} min(|P−V₀|,|P−V₁|) )   // 边界上正对边中点的位置
```

`c(r) <= 1000` 的解析下界为 `r >= 900√3 − 100√19 ≈ 1122.96m`；
默认取 `r = 1200m`（`c = 968.9m`，余量 31m）。用
`geometry.covering_radius` 可对任意方案做数值复核。

## 时间口径

| 项 | 耗时 |
| --- | --- |
| 移动 | 距离 / 5 m·s⁻¹ |
| 切换检测频道 | 1 s（同频道不切） |
| 测向 / 确认无信号 | 5 s |
| 光学精确定位 + 激光清除 | 3 s + 2 s |

计分用的是**虚拟时间**（机器狗在虚拟世界里的活动时长），上限 100 小时，通常不构成约束；
但程序运行时间（真实墙钟）上限 20 分钟，所以策略的计算必须足够快——
这也是把可行域裁剪做成 `O(边数)` 半平面裁剪、把最小包围圆做成增量 Welzl 的原因。
